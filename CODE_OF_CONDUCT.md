# Code of conduct

Treat contributors and users with respect. Critique ideas and code with clear
reasoning; do not attack people. Welcome questions and explain project decisions.

Harassment, threats, discriminatory abuse, sexualized conduct, doxxing and
publication of private information are not acceptable in issues, pull requests
or other project spaces. Do not pressure anyone to disclose personal details.

The maintainer may edit or remove harmful content, limit participation or ban
repeat offenders. Decisions should be proportionate to the behavior and explain
the reason where doing so does not reveal private information.

For a sensitive report, request a private contact channel from the maintainer
without publishing the incident details. Share only the information necessary
to understand the report. Good-faith reporters must not face retaliation.

These expectations apply equally to maintainers and contributors. Participation
is voluntary; contributors' time and boundaries should be respected.
