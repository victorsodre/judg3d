# Getting help

Start with the [README](README.md), [profile guide](profiles/README.md) and
[acceptance-gate demo](examples/acceptance-gate/README.md).

For a bug, use the bug report template and include the judg3d version, Node
version, operating system, profile and smallest shareable reproduction. State
whether the result was PASS (0), FAIL (1) or infrastructure failure (2).
A rejected asset is not necessarily a judg3d bug.

For usage questions or feature suggestions, use the corresponding issue template.
There is no dedicated support staff or response-time guarantee. A complete,
small reproduction is the most useful way to help the maintainer investigate.

Report vulnerabilities through [SECURITY.md](SECURITY.md). Do not put credentials,
proprietary assets or complete personal filesystem paths in public issues.
